# A4P Readwise Search

옵시디언 사이드 패널에서 Readwise highlights를 검색하고, 노트에 인용으로 삽입하거나 전용 노트로 변환하는 플러그인.

## 주요 기능

- **사이드 패널 검색** — 책·아티클·트윗·팟캐스트의 highlight를 키워드로 즉시 검색
- **필터** — 책, 카테고리, 태그로 좁히기 (책은 퍼지 검색 모달. 태그는 기본 접힘이며 "태그 열기"를 누르면 펼쳐집니다)
- **Daily Review 탭** — Readwise 오늘의 review를 한 번에 보기 + 전체 인용 일괄 삽입
- **인용 삽입** — 클릭 또는 드래그앤드롭으로 callout 형식 인용 삽입
- **Highlight → 메모 노트 생성** — 지정 폴더에 프론트매터 + `## 내 생각` 섹션 + 인용을 담은 단일 메모 자동 생성
- **분류 템플릿 연동 (선택)** — 노트 생성 직후 내 Templater 템플릿을 실행해 프론트매터 분류·태그를 자동으로 채움
- **삭제 반영** — Readwise에서 지운 하이라이트는 동기화 때 목록에서 빠짐. 메모 노트를 만들어 둔 하이라이트는 남고, 그 노트까지 지우면 목록에서도 빠짐
- **시각 보조** — 카테고리 컬러 칩, 상대 시간 배지(실제로 하이라이트한 날짜 기준), 검색어 마킹, 정렬 옵션(최신순·오래된순·관련도·책별 — 기본 정렬은 설정에서 변경)

## 설치 (BRAT 사용)

1. 옵시디언 커뮤니티 플러그인에서 **BRAT** 검색 → 설치 → 활성화
2. Cmd/Ctrl+P → "BRAT: Add a beta plugin for testing" 실행
3. 입력창에 `ai4pastor/a4p-readwise-search` 입력 → 추가
4. 옵시디언 설정 → 커뮤니티 플러그인에서 **A4P Readwise Search** 활성화

## 사용법

1. 설정 → **A4P Readwise Search**에서 "토큰 발급" 버튼 → Readwise에서 토큰 복사
2. 토큰 입력 → "토큰 검증" → 성공 확인
3. "전체 동기화" 클릭 → 모든 highlight 로컬 캐시 (이후에는 패널의 새로고침 버튼이나 명령 팔레트 "동기화 (증분)"으로 변경분만 받아옵니다 — 자동 동기화는 없습니다. Readwise에서 지운 항목도 이때 반영됩니다)
4. 좌측 리본의 책갈피(bookmark) 아이콘 또는 명령 팔레트 "A4P Readwise Search: 검색 패널 열기"
5. 검색어 입력 → 결과 카드에서:
   - **인용 삽입** 버튼 또는 카드 드래그 → 현재 노트에 callout
   - **노트 생성** 버튼 → 노트 폴더에 `{원본 제목 — 본문 스니펫}.md` 메모 (`## 출처` 인용 아래에 `## 내 생각` — 노트가 편집 모드로 열리고 커서가 내 생각 아래에 놓여 바로 쓸 수 있습니다). 이미 메모가 있는 highlight는 버튼이 **노트 열기**로 바뀌고(볼트 어느 폴더에 있어도 인식) 클릭하면 그 메모를 엽니다 — 이미 열린 탭이 있으면 그 탭으로 이동. 메모를 삭제하면 다시 **노트 생성**으로 돌아옵니다
   - **Readwise** 링크 → 해당 책 페이지에서 "Find similar highlights" 사용 가능

## 명령 팔레트

- `A4P Readwise Search: 검색 패널 열기`
- `A4P Readwise Search: Daily Review 열기`
- `A4P Readwise Search: 동기화 (증분)`

> 전체 다시 동기화는 실수 방지를 위해 명령 팔레트에 두지 않고, 설정 탭의 "전체 동기화" 버튼에서만 실행합니다.

## 정렬·시각 기준

- 카드의 상대 시간과 최신순/오래된순은 **실제로 하이라이트한 시각**(`highlighted_at`) 기준입니다. Readwise 쪽 갱신 시각(`updated_at`)은 공식 애플북스 앱이 재업로드할 때 옛 하이라이트에도 바뀌므로 쓰지 않습니다.
- 관련도는 검색어마다 본문 +3, 메모 +2, 책 제목 +1, 저자 +1, 태그 +1을 더한 점수이며, 동점이면 최근 하이라이트 순입니다. 검색어가 없으면 최신순과 같습니다.
- 기본 정렬은 설정 → 보기 → "기본 정렬"에서 바꿀 수 있습니다 (기본 최신순).

## 삭제 반영

- Readwise에서 하이라이트(또는 책)를 지우면 다음 동기화 때 검색 목록에서 빠집니다. 동기화 완료 메시지에 "삭제 반영 N건"으로 표시됩니다.
- **메모 노트를 만들어 둔 하이라이트는 남습니다.** 카드에 "Readwise에서 삭제됨" 표시가 붙고 버튼은 "노트 열기"로 유지되며, 인용 삽입도 그대로 됩니다.
- 그 메모 노트를 옵시디언에서 지우면 카드도 바로 사라지고, 다음 동기화 때 캐시에서도 정리됩니다.
- 이 기능이 들어간 버전(0.2.4)으로 올린 뒤 첫 동기화는 한 번 전체 동기화로 진행됩니다 (이전 캐시에 남아 있던 삭제 항목을 정리하기 위해서입니다).
- 노트를 휴지통에 둔 채 동기화하면 그 하이라이트는 캐시에서 빠집니다. 노트를 복원한 뒤 카드가 다시 필요하면 설정의 "전체 동기화"를 한 번 실행하세요.

## 분류 템플릿 연동 (선택, Templater 필요)

설정 → **Highlight 노트 생성** → "분류 템플릿 (Templater)"에 볼트 안의 Templater 템플릿(.md)을 지정하면, "노트 생성" 직후 그 템플릿이 새 노트를 대상으로 실행됩니다.

- 템플릿의 프론트매터 키(예: `created`, `world`, `outcome`, `route`, `doctrine`, `tags`, `source`, `related notes`)가 노트에 **추가**됩니다. 플러그인이 쓴 키(`book`, `author`, `highlight_id`, `readwise_url` 등)는 그대로 유지됩니다.
- 템플릿의 `<%* … %>` 스크립트가 실행됩니다. AI 분류 스크립트라면 노트 본문(인용)을 읽어 분류를 채웁니다. 스크립트가 쓴 `tags`는 Readwise 태그와 **합쳐지고**, `route`가 원소 하나짜리 목록이면 단일 값으로 정리되며, 빈 `source`에는 하이라이트의 Readwise 링크가 들어갑니다.
- 노트는 분류가 끝난 뒤 열립니다 (90초를 넘기면 먼저 열리고 뒤에 채워집니다). 템플릿이 없거나 Templater가 꺼져 있으면 안내만 뜨고 노트는 정상적으로 만들어집니다.
- 이미 존재하는 메모를 여는 경우에는 템플릿을 실행하지 않습니다.
- 비워 두면(기본) 이전과 똑같이 동작합니다. 입력란은 포커스만 해도 Templater 템플릿 폴더의 파일 목록이 뜨고, "검증" 버튼으로 파일·스크립트·Templater 상태를 확인할 수 있습니다.

## 데이터 저장

- Readwise highlights는 플러그인 `data.json`에 로컬 캐시 (옵시디언 vault 외부 통신 없음, Readwise API 한정)
- Readwise에서 지운 하이라이트는 메모 노트가 있는 것만 캐시에 남습니다 (`is_deleted` 표시)
- 생성된 메모는 설정의 "노트 폴더" 안에 평평하게 저장 (책별 하위 폴더 없음)
