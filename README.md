# A4P Readwise Search

옵시디언 사이드 패널에서 Readwise highlights를 검색하고, 노트에 인용으로 삽입하거나 전용 노트로 변환하는 플러그인.

## 주요 기능

- **사이드 패널 검색** — 책·아티클·트윗·팟캐스트의 highlight를 키워드로 즉시 검색
- **필터** — 책, 카테고리, 태그로 좁히기 (책은 퍼지 검색 모달. 태그는 기본 접힘이며 "태그 열기"를 누르면 펼쳐집니다)
- **Daily Review 탭** — Readwise 오늘의 review를 한 번에 보기 + 전체 인용 일괄 삽입 + **오늘 복습 완료** 표시(Readwise 복습 기록이 이어짐)
- **자동 동기화** — Obsidian을 켤 때 한 번, 그리고 설정한 간격(기본 1시간)마다 바뀐 것만 조용히 받아옴. 새 하이라이트가 있을 때만 알림
- **토큰 보관 위치** — 토큰을 지금처럼 플러그인 설정 파일에 두거나, Obsidian 키체인에 두어 `data.json`에 남지 않게 할 수 있음 (Obsidian 1.11.4 이상)
- **인용 삽입** — 클릭 또는 드래그앤드롭으로 인용 삽입. 형식은 콜아웃(기본)·짧은 인용·각주·사용자 정의 템플릿 가운데 고름
- **큰 검색 창** — 글을 쓰다가 `,,`(쉼표 두 번)를 치면 커서 위로 크게 열리는 창. 왼쪽에서 종류·책·태그·메모 있음·노트 만든 것·즐겨찾기·기간으로 좁히고(건수 표시), 가운데 목록에서 고르면 오른쪽에 전문·Readwise 메모·넣을 모양·같은 책의 앞뒤 밑줄이 보임. Enter를 누르면 `,,` 자리에 인용이 들어가고, 여러 개를 골라 한 번에 넣을 수도 있음
- **한국어 검색** — 초성으로 찾기(`ㅎㄴㄴ` → 하나님), 한영 전환을 잊고 친 글자 복원(`rleh` → 기도), 검색 문법(`"구절"` · `-빼기` · `책:` · `저자:` · `태그:`/`#태그` · `메모:`), 결과가 없으면 조사·어미를 떼고 다시 찾고("소망을" → "소망") 그래도 없으면 일부 낱말만 맞는 결과, 큰 검색 창의 최근 검색어
- **Highlight → 메모 노트 생성** — 지정 폴더에 프론트매터 + `## 내 생각` 섹션 + 인용을 담은 단일 메모 자동 생성
- **분류 템플릿 연동 (선택)** — 노트 생성 직후 내 Templater 템플릿을 실행해 프론트매터 분류·태그를 자동으로 채움
- **삭제 반영** — Readwise에서 지운 하이라이트는 동기화 때 목록에서 빠짐. 메모 노트를 만들어 둔 하이라이트는 남고, 그 노트까지 지우면 목록에서도 빠짐
- **시각 보조** — 카테고리 컬러 칩, 상대 시간 배지(실제로 하이라이트한 날짜 기준), 검색어 마킹, 정렬 옵션(최신순·오래된순·관련도·책별 — 기본 정렬은 설정에서 변경)

## 설치 (BRAT 사용)

1. 옵시디언 커뮤니티 플러그인에서 **BRAT** 검색 → 설치 → 활성화
2. Cmd/Ctrl+P → "BRAT: Add a beta plugin for testing" 실행
3. 입력창에 `ai4pastor/a4p-readwise-search` 입력 → 추가
4. 옵시디언 설정 → 커뮤니티 플러그인에서 **A4P Readwise Search** 활성화

## 사용법

1. 설정 → **A4P Readwise Search**에서 "토큰 발급" 버튼 → Readwise에서 토큰 복사
2. 토큰 입력 → "토큰 검증" → 성공 확인
3. "전체 동기화" 클릭 → 모든 highlight 로컬 캐시. 그다음부터는 **자동 동기화**가 Obsidian을 켤 때와 1시간마다(설정에서 끔·15분~3시간) 바뀐 것만 받아옵니다. 바로 받고 싶으면 패널의 새로고침 버튼이나 명령 팔레트 "동기화 (증분)"을 쓰세요. Readwise에서 지운 항목도 이때 반영됩니다
4. 좌측 리본의 책갈피(bookmark) 아이콘 또는 명령 팔레트 "A4P Readwise Search: 검색 패널 열기"
5. 검색어 입력 → 결과 카드에서:
   - **인용 삽입** 버튼 또는 카드 드래그 → 현재 노트에 callout
   - **노트 생성** 버튼 → 노트 폴더에 `{원본 제목 — 본문 스니펫}.md` 메모 (`## 출처` 인용 아래에 `## 내 생각` — 노트가 편집 모드로 열리고 커서가 내 생각 아래에 놓여 바로 쓸 수 있습니다). 이미 메모가 있는 highlight는 버튼이 **노트 열기**로 바뀌고(볼트 어느 폴더에 있어도 인식) 클릭하면 그 메모를 엽니다 — 이미 열린 탭이 있으면 그 탭으로 이동. 메모를 삭제하면 다시 **노트 생성**으로 돌아옵니다
   - **Readwise** 링크 → 해당 책 페이지에서 "Find similar highlights" 사용 가능
6. 노트를 쓰는 중에는 패널 없이도 인용할 수 있습니다:
   - **큰 검색 창 여는 법**: 노트에서 `,,`(쉼표 두 번)를 치거나, 명령 팔레트 "큰 검색 창 열기"(설정 → 단축키에서 단축키 지정 가능)를 실행하거나, 사이드 패널의 **크게 보기**를 누릅니다(지금 검색어·필터가 그대로 넘어감). 여는 글자는 설정에서 바꾸거나 끌 수 있습니다(a4p 성경구절 플러그인이 쓰는 `;;`·`;;;`와 겹치지 않게 기본값을 `,,`로 정했습니다). 코드 블록·인라인 코드·프론트매터 안에서는 열리지 않고, 붙여넣기나 되돌리기로는 열리지 않습니다.
   - **창 안에서**: 검색칸에 바로 치면 됩니다. ↑↓ 이동, Enter 인용 넣기(`,,`로 열었으면 그 자리, 아니면 마지막으로 쓰던 노트의 커서 자리), Shift+Enter 메모 노트 만들기·열기, ⌥Enter(윈도우 Alt+Enter) 여러 개 고르기, ⌘Enter(윈도우 Ctrl+Enter) 고른 것 한 번에 넣기, Esc 닫기(`,,`는 그대로 남음). 카드를 두 번 눌러도 넣어집니다.
   - **필터**: 각 필터 옆 숫자는 눌렀을 때 남을 건수입니다. 책 목록은 "책·저자 찾기"로 좁힐 수 있고, "필터 초기화"로 한 번에 풉니다.
   - **미리보기**: 형식(콜아웃·짧은 인용·각주·사용자 정의)을 바꾸면 "넣을 모양"이 바로 바뀌고 설정에도 저장됩니다. "같은 책의 앞뒤 밑줄"을 누르면 그 밑줄로 옮겨 갑니다.
   - 좁은 화면·모바일에서는 한 단으로 접히고, "필터" 단추와 카드 누르기로 필터·미리보기를 엽니다.

## 명령 팔레트

- `A4P Readwise Search: 검색 패널 열기`
- `A4P Readwise Search: 큰 검색 창 열기 (하이라이트 찾아 인용)`
- `A4P Readwise Search: Daily Review 열기`
- `A4P Readwise Search: 동기화 (증분)`

> 전체 다시 동기화는 실수 방지를 위해 명령 팔레트에 두지 않고, 설정 탭의 "전체 동기화" 버튼에서만 실행합니다.

## 정렬·시각 기준

- 카드의 상대 시간과 최신순/오래된순은 **실제로 하이라이트한 시각**(`highlighted_at`) 기준입니다. Readwise 쪽 갱신 시각(`updated_at`)은 공식 애플북스 앱이 재업로드할 때 옛 하이라이트에도 바뀌므로 쓰지 않습니다.
- 관련도는 검색어마다 본문 +3, 메모 +2, 책 제목 +1, 저자 +1, 태그 +1을 더한 점수이며, 동점이면 최근 하이라이트 순입니다. 검색어가 없으면 최신순과 같습니다.
- 기본 정렬은 설정 → 보기 → "기본 정렬"에서 바꿀 수 있습니다 (기본 최신순).

## 검색 규칙

검색어를 띄어 쓰면 **모든 낱말이 든** 하이라이트를 찾습니다. 결과가 없을 때만 차례로 넓혀 찾습니다. 상태 줄에 어느 단계로 찾았는지와 검색 조건이 표시됩니다.

1. 모든 낱말 포함 (결과가 있으면 여기서 끝)
2. 영문 자판으로 친 낱말을 한글로 바꿔 찾기 — 한영 전환을 잊고 친 `rleh` → "기도" (온전한 두 음절 이상이 될 때만, 영어 낱말은 바꾸지 않음)
3. 조사·어미를 뗀 낱말로 다시 찾기 — "소망을 붙드는" → "소망 붙드"
4. 낱말 절반 이상이 맞는 결과를 **본문에서 맞은 낱말 수** 순으로 보여 주기 — "고난 속에서 소망을 붙드는 법" 같은 문장형 검색

**검색 문법** (큰 검색 창의 "검색 문법" 단추를 누르면 예시가 나오고, 누르면 검색칸에 붙습니다)

- `ㅎㄴㄴ` — 초성으로 찾기. 먼저 한 낱말 안에서 찾고, 없으면 띄어쓰기를 건너뛰고 찾습니다(`ㅎㄴㄴㅅㄹ` → "하나님 사랑"). 맞은 글자에 강조가 칠해집니다
- `"하나님의 은혜"` — 따옴표 안은 띄어쓰기까지 그대로
- `-번영` — 이 낱말이 든 밑줄은 빼기
- `책:기도` · `저자:김` · `태그:설교`(또는 `#설교`) · `메모:적용` — 그 칸에서만 찾기. 앞에 `-`를 붙이면 그 칸에 든 것을 빼고, 띄어쓰기가 있으면 `책:"기도의 능력"`처럼 따옴표로 묶습니다
- 큰 검색 창은 결과가 있었던 검색어를 **최근 검색**으로 기억했다가, 검색칸이 비어 있을 때 칩으로 보여 줍니다(8개, "지우기"로 비움)

뜻이 비슷한 다른 낱말(예: "고난"과 "환난")까지 찾는 의미 검색은 아직 없습니다.

## 인용 형식

설정 → **인용 넣기** → "인용 형식"에서 고릅니다. 인용 삽입 버튼, 드래그, Daily Review, 큰 검색 창에 모두 적용됩니다. 설정 화면에서 바로 미리 볼 수 있습니다.

- **콜아웃 (기본)** — `> [!quote] 책 — 저자` 아래에 본문·메모·링크 (이전 버전과 같은 모양)
- **짧은 인용** — `“본문” (저자, 『책』, p. 12)` 한 줄. 책은 『』, 아티클·트윗 등은 「」로 묶고, 쪽수(p.)·킨들 위치가 있을 때만 붙입니다
- **각주** — `“본문”^[저자, 『책』, p. 12.]` 옵시디언 인라인 각주라 읽기 화면에서 번호 각주로 보입니다. 아티클은 원문 주소가 각주에 들어갑니다. 과제·논문용
- **사용자 정의 템플릿** — 변수 `{{text}}` `{{note}}` `{{title}}` `{{author}}` `{{location}}` `{{date}}` `{{category}}` `{{url}}` `{{source_url}}` `{{readwise_url}}` `{{id}}`를 씁니다. 값이 모두 빈 줄은 빠지고, `{{#author}} — {{author}}{{/author}}`처럼 쓰면 값이 있을 때만 들어갑니다. 여러 줄 본문은 그 줄의 `>`를 이어 붙여 콜아웃이 끊기지 않습니다

메모 노트(`## 출처`)의 인용은 형식 설정과 관계없이 콜아웃으로 만들어집니다.

## 삭제 반영

- Readwise에서 하이라이트(또는 책)를 지우면 다음 동기화 때 검색 목록에서 빠집니다. 동기화 완료 메시지에 "삭제 반영 N건"으로 표시됩니다.
- **메모 노트를 만들어 둔 하이라이트는 남습니다.** 카드에 "Readwise에서 삭제됨" 표시가 붙고 버튼은 "노트 열기"로 유지되며, 인용 삽입도 그대로 됩니다.
- 그 메모 노트를 옵시디언에서 지우면 카드도 바로 사라지고, 다음 동기화 때 캐시에서도 정리됩니다.
- 이 기능이 들어간 버전(0.2.4)으로 올린 뒤 첫 동기화는 한 번 전체 동기화로 진행됩니다 (이전 캐시에 남아 있던 삭제 항목을 정리하기 위해서입니다).
- 노트를 휴지통에 둔 채 동기화하면 그 하이라이트는 캐시에서 빠집니다. 노트를 복원한 뒤 카드가 다시 필요하면 설정의 "전체 동기화"를 한 번 실행하세요.

## 분류 템플릿 연동 (선택, Templater 필요)

설정 → **Highlight 노트 생성** → "분류 템플릿 (Templater)"에 볼트 안의 Templater 템플릿(.md)을 지정하면, "노트 생성" 직후 그 템플릿이 새 노트를 대상으로 실행됩니다.

- 템플릿의 프론트매터 키(예: `created`, `world`, `outcome`, `route`, `doctrine`, `tags`, `source`, `related notes`)가 노트에 **추가**됩니다. 플러그인이 쓴 키(`book`, `author`, `highlight_id`, `readwise_url` 등)는 그대로 유지됩니다.
- 템플릿의 `<%* … %>` 스크립트가 실행됩니다. AI 분류 스크립트라면 노트 본문(인용)을 읽어 분류를 채웁니다. 스크립트가 쓴 `tags`는 Readwise 태그와 **합쳐지고**, `route`가 원소 하나짜리 목록이면 단일 값으로 정리되며, 빈 `source`에는 하이라이트의 Readwise 링크가 들어갑니다.
- 노트는 분류가 끝난 뒤 열립니다 (90초를 넘기면 먼저 열리고 뒤에 채워집니다). 템플릿이 없거나 Templater가 꺼져 있으면 안내만 뜨고 노트는 정상적으로 만들어집니다.
- 이미 존재하는 메모를 여는 경우에는 템플릿을 실행하지 않습니다.
- 비워 두면(기본) 이전과 똑같이 동작합니다. 입력란은 포커스만 해도 Templater 템플릿 폴더의 파일 목록이 뜨고, "검증" 버튼으로 파일·스크립트·Templater 상태를 확인할 수 있습니다.

## 토큰 보관

설정 → **토큰 보관 위치**에서 고릅니다 (Obsidian 1.11.4 이상에서 보임).

- **플러그인 설정 파일 (기본)** — 지금처럼 `data.json`에 저장됩니다. 휴대폰 등 여러 기기에서 그대로 씁니다.
- **Obsidian 키체인** — 이 기기에만 암호화해 보관하고 `data.json`에는 남기지 않습니다. 볼트를 남과 공유하거나 백업·GitHub에 올린다면 이쪽이 안전합니다. 키체인은 기기마다 따로라서 다른 기기에서는 토큰을 한 번 더 넣어야 합니다(넣으라는 안내가 뜹니다).
- 바꾸면 지금 토큰이 새 위치로 옮겨지고 옛 위치에서는 지워집니다. 토큰 입력칸은 화면 공유 때 보이지 않게 가려 두며, 눈 단추로 잠깐 볼 수 있습니다.

## 데이터 저장

- Readwise highlights는 플러그인 `data.json`에 로컬 캐시 (옵시디언 vault 외부 통신 없음, Readwise API 한정)
- Readwise에 쓰는 동작은 Daily Review의 "오늘 복습 완료" 하나뿐입니다 (하이라이트·메모·태그는 바꾸지 않습니다)
- Readwise에서 지운 하이라이트는 메모 노트가 있는 것만 캐시에 남습니다 (`is_deleted` 표시)
- 생성된 메모는 설정의 "노트 폴더" 안에 평평하게 저장 (책별 하위 폴더 없음)
